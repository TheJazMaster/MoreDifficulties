# More Difficulty Options
This is a mod for Cobalt Core that holds an accessibility option, additional reimagined hardest difficulties, options for more run-start variety and some quality of life for randomizing your crew.

## Alt Starters
A character's starter cards shape their playstyle a lot. This mod adds a second set you can toggle per character, for every vanilla character (and almost all modded characters implement their own alt starters too). You can play Max with actual damaging cards or start off with stuns as Dizzy, and more. Simply press the character icon again to toggle their alt starters (and press it again to unselect the character).

## Easy mode
A simple accessibility difficulty from **Shockah**'s old mod. You gain 1 temp shield each turn.

## Brutal mode
Vanilla Cobalt Core is very exploitable. Brutal difficulty offers everything Hardest does and these additions:
- Shuffling your deck makes trash. This singlehandedly destroys easy infinites and encourages making bigger decks.
- Basic cards have different upgrades, so they can no longer become 0 energy without exhausting.
- The healing you receive from defeating a boss is halved. Damage you take in zone 1 might actually matter now.
- You can only store 7 evade at a time. A generous cap, but it still prevents farming it endlessly.
Personally, I dislike playing a game where I know making a tiny deck with an infinite combo would be the best course of action, so I made this difficulty to nerf that low-fun optimal strategy, and improve some other decision-making.


## Cosmic mode
Most of the enemies in later zones, and especially the Cobalt itself, are kind of pushovers. The game doesn't ramp up enough or require diverse solutions, hence, this difficulty buffs some zone 2 enemies (particularly Evil Riggs) and greatly buffs almost every zone 3 enemy (especially the Cobalt). See the changes for yourself.

## Randomization locks and bans
A simple change to make "randomize" enjoyers happy. You can right click (or cancel on controller) a selected character to lock them or an unselected character to ban them. Locked characters will always be chosen by the randomize buttons, and banned ones never will. You can do the same to ships with Nickel's new ship selection UI.

## Mod compatibility
This mod works with every other known mod, provides alt starters for almost every known character mod and provides its extra difficulty features as selectable modifiers when combined with the [Custom Run Options](https://www.nexusmods.com/cobaltcore/mods/60) mod.
